# Changelog

## [1.0.0] - 2026-08-04
### Initial Release
- Real-time WebSocket broadcast of attack events
- Animated bezier arc visualization on Leaflet map
- SSH honeypot database integration
- Demo mode with realistic generated attacks
- GeoIP enrichment via ipapi.co
- Live statistics sidebar (top sources, attack types)
- Live feed panel (scrolling attack log)
- Speed control for demo playback
- Docker + docker compose deployment
- Auto-fallback to demo mode if no honeypot.db present
